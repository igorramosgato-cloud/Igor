# Integração Questor × Sankhya

Aplica-se ao processo P02 (Auditoria Questor × Sankhya).

## Regra

- Nunca gravar diretamente no Questor a partir de uma comparação com o
  Sankhya sem homologação prévia — o resultado da auditoria é um relatório
  de divergências, não uma gravação automática, até que isso seja
  explicitamente aprovado.
- Ver `.claude/rules/matching.md` para a chave de correspondência entre os
  dois sistemas.
- Toda divergência deve indicar claramente qual sistema é considerado fonte
  de verdade para aquele campo específico (isso varia por campo, não é
  global).
