# Contexto do projeto

O JR DP Automation Hub existe para transformar rotinas manuais de
Departamento Pessoal (DP) em automações confiáveis, seguindo a metodologia:

dados → estruturação → mapeamento → validação → automação → QA → operação

O objetivo desta pasta de documentação é que o histórico de decisões e o
estado do projeto vivam no repositório, não em uma conversa — ver `CLAUDE.md`
e `state/PROJECT_STATE.md`.
