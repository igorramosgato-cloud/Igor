# Governança de Fontes — 2026-09-05

Registro da governança aprovada para o projeto, incorporada às regras
permanentes em `.claude/rules/governanca.md`.

## Princípios

1. Nenhuma automação é construída sobre uma fonte de dados não registrada.
2. Nenhuma decisão de negócio é assumida sem evidência — decisões ficam em
   `docs/DECISIONS.md`.
3. Erros históricos identificados são documentados para não serem
   reaproveitados por engano.
4. Toda regra regulatória cita fonte oficial (ver `.claude/rules/regulatorio.md`).

Esta governança se aplica a todos os processos do roadmap (`docs/BACKLOG.md`).
